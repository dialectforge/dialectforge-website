Build with your AI

I build by directing AI, and you can too. Vibe coders are welcome. Paste one of these prompts into your AI assistant (Claude, ChatGPT, Grok, Cursor, Codex or similar). Each one points it at /llms.txt, a plain map of this site for AIs, and at the repository's AGENTS.md.

§ 1 Prompts

Wrap my LLM app with Cattledog

Read https://dialectforge.com/llms.txt, then https://dialectforge.com/cattledog/index.md, then AGENTS.md and README.md in https://github.com/dialectforge/cattledog.
I want to add Cattledog (honesty + scars) around the LLM in my project. Ask me which model I use, which tools it can call, and what a wrong answer would cost. Then propose a small plan for me to approve before you write code.
Be honest: Cattledog is a proof of concept, not a security product. Its results are the author's own and not independently reproduced. It is Apache-2.0.

Run Lu and explain it to me

Read https://dialectforge.com/llms.txt, then https://dialectforge.com/lu/index.md, then AGENTS.md and docs/LU_EXPLAINED.md in https://github.com/dialectforge/lu.
Help me clone, build and test Lu (cargo build, cargo test), then ingest a tiny dataset and ask it a question. Explain each step in plain words.
Don't claim anything works until we've run it. Lu is research code under AGPL-3.0 (commercial license from DialectForge LLC).

Contribute a fix

Read https://dialectforge.com/llms.txt and AGENTS.md and CONTRIBUTING.md in the repo I name (https://github.com/dialectforge/lu or https://github.com/dialectforge/cattledog).
Pick one item from "Where to start" in AGENTS.md, explain your plan, make the change with a test, run the tests, and draft a pull request that honestly says what you tested. Never commit secrets or personal data.

Explore the Lu + Cattledog + Jev idea

Read https://dialectforge.com/llms.txt and https://dialectforge.com/research/lu-cattledog-jev/index.md.
It's an unbuilt proposal. Help me design the smallest experiment that would show whether a persistent overseer (Lu) with honesty and scars (Cattledog) makes LLM agents better, and how we'd measure it against agents without it.
