Start with an AI agent

If you use an AI coding agent, paste one of these prompts into it. Each one points the agent at the project's AGENTS.md, the protocol notes and the license, then has it plan an integration with you before writing code.

§ 1 Prompts

Which repositories are public

Lu (AGPL-3.0) and Cattledog (Apache-2.0) are public now. The other DialectForge projects are still being cleaned up, so their links won't open yet; their prompts will work unchanged once they do. See also Build with your AI.

§ 2 What's in AGENTS.md

Every DialectForge repository has an AGENTS.md that covers what the project is, its honest status, the files to read first, how to build and test it, the protocol concepts it uses (seed-negotiated dialects, the 2-minute refresh, dropping foreign frames), where to plug it in, the license, and what not to claim. Nothing in these projects has been independently audited.

An agent does better work when it reads the plans first. These prompts make sure it does.
