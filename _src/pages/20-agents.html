Start with an AI agent

If you use an AI coding agent, paste one of these prompts into it. Each one points the agent at the project's AGENTS.md, the protocol notes and the license, then has it plan an integration with you before writing code.

§ 1 Prompts

The repositories aren't public yet

They're being cleaned up and will be published under AGPL-3.0 soon. Until then the links in these prompts won't open. The prompts are written so they work unchanged once the repositories are public.

§ 2 What's in AGENTS.md

Every repository has an AGENTS.md that covers what the project is, its honest status, the files to read first, how to build and test it, the protocol concepts it uses (seed-negotiated dialects, the 2-minute refresh, dropping foreign frames), where to plug it in, the license, and what not to claim. Nothing in these projects has been independently audited.

An agent does better work when it reads the plans first. These prompts make sure it does.
