FlowState Open source · MIT

A shared project memory for your AI apps. Free, open source and local-first. FlowState is an MCP server for Claude, ChatGPT, Cursor, Grok and any other MCP client. Your data stays on your machine.

§ 1 What it is

One memory for every AI app you use

Without shared memory, each new AI chat starts from scratch. FlowState gives all of your AI apps the same memory of your projects: todos, changes, decisions, problems and lessons learned. Your AI reads a short brief when it starts work on a project and writes down what happens as it goes. The next chat, or the next app, picks up where the last one stopped.

Everything lives in one SQLite file on your computer. Nothing is sent anywhere unless you turn on an optional feature that does so: an off-site backup to your own private GitHub repo, or remote access through your own Cloudflare Tunnel.

Works with

  • Claude Desktop, Claude Code, Cursor, Windsurf, Codex CLI and Grok Build, on the same computer. The setup script connects them for you.
  • claude.ai and ChatGPT, through the optional remote access.
  • Any other MCP client, locally or over your network with a key.
§ 2 Many AIs

Many AIs, one memory, at the same time

Claude, ChatGPT, Cursor and Grok can all use FlowState at once, on your computer, across your network, or from your phone. When one AI logs a decision or a change, the others see it the next time they check. Hard rules and handoff notes reach every AI, and every change records which AI made it, so you always know who did what. Work across projects is linked too, so a change to something shared shows up in every project that uses it.

§ 3 Story

Why I built it

I built FlowState v1 in January 2026 as a gift to the vibe coder community, back when context was a serious bottleneck and every new AI chat started from scratch. This week I updated it, because the bottleneck moved. Now most of us work across several AI platforms at once, and keeping context between them is the new problem. FlowState stays free and local.

John Martin, DialectForge

§ 4 Features

What it does

Memory your AI actually reads

  • The start_here brief: one call gives your AI the project's hard rules, handoff notes, open todos, problems, recent changes, decisions and key lessons. Pick quick, standard or deep, depending on how much context you want to spend.
  • One tool to write things down: log_work records a decision, change, problem, lesson or todo. Every write has to name a project, so nothing lands in the wrong place.
  • Automatic sessions: a session opens on the first call for a project and closes after two hours idle or when the app quits, with a short summary that waits for your review.

You stay in charge

  • Hard rules: "never do this" rules for each project, always shown in full at the top of the brief.
  • Handoff notes between AIs: an AI that has to stop mid-task leaves "where I was, next step". The next AI, in any app, sees it first until it picks it up.
  • Review queue: auto-captured summaries, and anything the AI marks as a suggestion, wait for your OK. Approve, edit or reject them in chat or on the review page.
  • Review modes: you choose how much needs your OK: off, auto-captured only (the default), chosen record types, or everything. Set it for the whole install or per project. The AI may change it only when you ask in the chat, and every change is logged with your words.
  • Browser review page: a small page on your own computer (one-time link, this computer only) with the review queue, review mode, a pause switch for each app, and "Who did what".
  • Edit history with undo: edits made through FlowState are kept. You can see them and undo the last change to a record, and an undo can itself be undone.
  • Superseded decisions: a new decision can name the one it replaces, so only the current one shows in the brief.
  • Source, confidence and "last checked": records can say where they came from (you said it, the AI inferred it, or it was read from the code), and solution attempts carry a confidence level from "attempted" to "proven". Facts like paths, ports and settings that haven't been checked for 60 days are flagged for re-checking.

Accountability

  • Which app, machine and model made each change: edits, review items, decisions, links, handoffs, hard rules, review-mode changes and the activity log all record the app, the machine or workspace, the AI model (when the app supplies it) and how the app was identified.
  • "Who did what" view: filter changes by app, model, machine, project and time on the review page, and undo a change from there.
  • Per-app keys: give each app its own key, optionally read-only, so the recorded app name comes from the key rather than from what the app says about itself. The key is shown once, only a hash is kept, and a revoked key stops working at once.
  • Activity log and pause: see which app did what, and pause one app's writes. A paused app can still read.

Projects, tasks and finding things

  • Todos with priorities: critical, urgent, normal and low, plus subtasks, blockers and a "what's next" list of open, unblocked work, highest priority first.
  • Cross-project links: when several projects share one thing, link them. A change logged on the shared part gives every linked project an update todo and a "changed since you last looked" note. FlowState alerts; it never changes code in other projects.
  • GitHub and Linear links: attach an issue or pull request to a todo, problem or other record.
  • Ask in plain language: ask a question in your own words. FlowState answers by quoting your own records, with their ids, and says so when it has nothing on it. It doesn't make anything up.
  • Search: keyword search across todos, decisions, changes, lessons, problems and solutions. Search by meaning is optional and uses a local model you install yourself.
  • Clean-up suggestions: likely duplicates, stale items and records filed under the wrong project go to the review queue. Nothing moves until you approve.

Bringing things in and out

  • Import your memories: bring a Claude or ChatGPT memory export (text, Markdown or JSON) into the review queue, so you decide what is kept.
  • Markdown export and import: write a readable copy of a project, edit it, and bring your edits back through the review queue.
  • Opt-in git capture: off by default. Turn it on for a project and new commit subjects become changes (subject lines only; no author, e-mail or diff).

Safety and backups

  • Secret refusal: a write that looks like it contains a key, token, password, private key or card number is refused and not saved. A command lists older records that look suspicious, without showing their values.
  • Token in your OS credential store: Windows Credential Manager, the macOS Keychain, or a private file on Linux.
  • Nightly backups: integrity-checked, with 14 daily and 8 weekly copies kept. A restore goes to a new file unless you force it.
  • Optional private GitHub off-site copy: FlowState checks that the repo is private before every push and refuses otherwise. It never stores a GitHub token.

Connecting

  • Local and network connections: apps on the same computer connect directly; other machines on your network use a token or a per-app key.
  • Optional remote access through your own tunnel: for cloud AIs such as claude.ai and ChatGPT, FlowState can listen behind your own Cloudflare Tunnel, with a sign-in you approve using your owner passphrase and per-app tokens you can revoke (optionally read-only).
  • Fewer tools if you want: a core mode lists only the 9 core tools to save context; the others still work if called.

The v1.1 desktop GUI was an unfinished experiment and has been removed. FlowState 2 is used through your AI and the browser review page.

§ 5 Free

Free, with no paid tier

Many AI memory tools now put their best features behind subscriptions: Mem0 ($19 to $249/mo), Zep ($125/mo and up), Supermemory ($19/mo and up). Some have dropped their free or self-hosted options entirely, like Zep's self-hosted edition and Pieces' free tier. FlowState is MIT-licensed, runs on your own machine, and is free with no paid tier.

§ 6 Not limited

Think of a feature? Have your AI build it

FlowState is open source and written to be worked on by AI. AGENTS.md and llms.txt explain the repo, the code is split into small modules, and there's a test suite that runs against temporary databases. If you think of a feature, have your own AI build it. You're not waiting on a vendor's roadmap.

§ 7 Honest limits

What it doesn't do

  • The AI model is recorded only when the app supplies it. FlowState never guesses one. If the app says nothing, the model is left empty.
  • Desktop app and machine names are self-reported. They are a convenience, not security. Only per-app keys, per-app remote tokens and approved sign-ins give an identity an app can't pick for itself, and "Who did what" shows which kind each change used.
  • Tested mainly on Windows and macOS. Linux should work but is less tested.
  • "Only when you ask" is enforced by wording, not cryptography. Approving review items and changing the review mode require the AI to quote your words, but a misbehaving AI could make them up. FlowState can't stop an AI from doing something outside FlowState.
  • Search by meaning needs a model you install yourself. FlowState never downloads a model or calls a cloud API. Without one, search and ask match words only, so a reworded question can miss.
  • Ask quotes; it doesn't write. It returns the best-matching sentences from your records rather than new answers.
  • Remote access is optional and takes setup: your own domain on Cloudflare, cloudflared on your computer, and an owner passphrase.
  • The secret scanner is pattern-based. It can refuse harmless text and miss a short secret without a label.
  • Undo covers edits made through FlowState. Creating a record isn't undone, and changes made directly in the database aren't tracked.
  • The off-site copy keeps one backup. History depth comes from your local backups.

The full list is in the README's "Honest limits" section.

§ 8 Get it

Set it up with your AI

Paste this into an AI app that can run commands on your computer (Claude Code, Cursor, Windsurf, Codex CLI, Grok Build and others). It reads the repo's AGENTS.md, asks which apps to connect and whether you want nightly backups, shows you a dry run, then runs the setup script. When it's done, fully quit and reopen the apps it connected.

Set up FlowState for me from https://github.com/dialectforge/FlowState by following its AGENTS.md.

Prefer to do it yourself? It needs Python 3.11 or newer and git. The README has the manual install steps.
