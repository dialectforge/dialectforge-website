Terminal / SSH

Server administration with SSH carried inside DialectForge. The goal is to hide the connection itself from network monitors, not just its content.

§ 1 Compare

Standard SSH · ssh root@server

  • Known port 22
  • Recognizable SSH handshake
  • Port scanners find it fast
  • Brute-force attempts around the clock
  • Traffic pattern shows admin activity

DF Terminal · dialectforge connect server-eu

  • Non-standard port, designed not to answer scanners
  • SSH wrapped in a DF dialect
  • Traffic designed to look like random noise
  • Three factors required before a shell
  • Dialect refreshes every 2 minutes

§ 2 Layers
L1TOTP code

A time-based one-time code from your authenticator app. New every 30 seconds.

L2Session token

Issued after TOTP, scoped to this one session, not reusable.

L3Certificate pinning

A pinned client certificate. If it doesn't match exactly, the connection is closed. No fallback.

+DialectForge underneath

All of the above happens inside a dialect that changes every two minutes.

The pieces: a Python server-side SSH proxy with a systemd unit, a command-line client, and native macOS and iPad apps. Each one carries its own copy of the dialect engine.
