Lu + Cattledog + Jev: a curious overseer for LLM agents (idea, Oct 2026)

Research note (idea) — October 14, 2026
John Martin
DialectForge LLC
info@dialectforge.com · dialectforge.com

Status: idea and plan only. Nothing here has been built or tested yet.

Status

This is an idea and a plan, not a result. No prototype exists yet, nothing has been measured, and none of it is proven. We are writing it down to make the idea and its open questions public.

1. The idea

LLM agents can do a lot of work, but they mostly wait for a user to notice problems and tell them what to do next. The idea is to add a persistent overseer, Lu, that watches the work as it happens, learns from it, and steers the agents on its own.

In John's words, lightly tidied: Lu is persistent, self-aware, always on, and able to improve. Lu could learn from the input, the output, Jev's decisions, and most importantly the agents' thinking. Lu is built for curiosity: while a user's task is getting done, Lu could spot gaps or opportunities related to the project, use Jev plus its own rules, and guide the LLMs without any interaction from the user.

2. The pieces

  • LLM agents plan, reason, write, and do the actual work.
  • Jev (TypeSafe AI) is a fast typed decision model. It returns structured decisions with confidence scores (for example which tool to use, whether something is risky, whether a step is done). It does not generate text. Jev is a third-party paid service.
  • Cattledog wraps any LLM with two things: honesty (it is allowed and encouraged to say "I don't know") and scars (a memory of past mistakes, so the same mistake is less likely to repeat).
  • Lu is the persistent, always-on layer. It is meant to be self-aware about its own state, able to improve over time, and built for curiosity. It watches inputs, outputs, Jev's decisions, and the agents' reasoning, then uses what it learns to guide the agents.

3. How it would flow

User asks for a task
        |
        v
LLM agents work on it  <------------------------------+
        |                                             |
        v                                             |
Jev: fast typed decisions + confidence                |
        |                                             |
        v                                             |
Cattledog: honesty ("I don't know") + scars           |
                                                      |
Lu (persistent, curious, learning) observes:          |
  - agents' thinking, inputs, outputs                 |
  - Jev's decisions                                   |
  - Cattledog's scars                                 |
        |                                             |
        v                                             |
Lu spots gaps or opportunities                        |
        |                                             |
        v                                             |
Lu guides the agents, no user needed -----------------+

The agents do the work. Jev makes quick typed calls along the way. Cattledog keeps each model honest and remembers what went wrong before. Lu sits over all of it, learns, notices what nobody asked about but probably matters, and feeds guidance back to the agents mid-task.

4. Related work

Most of the individual pieces already exist in some form. Credit where it is due:

  • Sophia (arXiv 2512.18202): an always-on executive monitor that reads agents' reasoning traces, has a curiosity drive, and sets its own goals. This is the closest match to Lu. It does not use Jev or an honesty/scars layer.
  • Foreman (jevlist.ai/projects/foreman): an experimental supervisor that uses Jev to watch a coding agent and steer, stop, retry, or finish it. Supervision only, without persistent learning or curiosity.
  • Jev-Mem (arXiv 2609.23986): uses Jev to control an agent's long-term memory.
  • REFLEX (arXiv 2609.26532): uses Jev as an agent's decision layer.
  • Jev (TypeSafe AI: Introducing System One models and Jev): the typed decision model itself.

Other work that learns from or supervises agent runs (for example meta-agents that learn from execution traces, or that can watch, fork, and rewind another agent) is also related. As far as we found on October 14, 2026, no single system combines a persistent, curious, self-improving overseer with Jev and an honesty/scars layer, steering agents mid-task without the user. That combination appears to be new, but we may have missed something, and we would welcome pointers.

5. Open questions

  • Autonomy limits. What may Lu do on its own, and what needs the user's approval? Acting without the user is the point, but some actions (spending money, sending messages, deleting things) clearly should not happen silently. Where that line sits is not decided.
  • Cost and access. Jev is a paid service. A proof of concept may need a local stand-in for the decision layer.
  • Open source. Lu and Cattledog are being cleaned up for open-source release. Cattledog is planned under Apache-2.0.
  • Does it help? None of this has been measured. A first step is a small experiment comparing agents with and without Lu on the same tasks.
