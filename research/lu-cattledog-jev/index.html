Lu + Cattledog + Jev + LLM agents: an idea for more autonomous AI

John Martin, DialectForge · October 14, 2026

Status: proposal

This is an idea written down, not a result. Nothing here has been built, proven or tested. The parts described below exist separately; the combination does not, as far as we know. Lu and Cattledog are open source now.

1. The idea

Lu is a persistent AI that is always on, aware of its own state, and able to improve itself. It is built around curiosity. The idea is to let Lu learn from what LLM agents take in, what they produce and, most of all, how they think, and from the decisions Jev makes along the way. While a user's task is running, Lu could notice gaps or opportunities related to the project, check them with Jev and its own rules, and guide the agents without the user having to step in.

2. The pieces

  • LLM agents plan, reason, write and do the work.
  • Jev (from TypeSafe AI) is a fast “System One” model. It returns typed decisions with confidence scores, for example which tool to use, whether a step is risky, or whether a task is done. It does not generate text. Jev is a third-party, paid service; it is not made by DialectForge. TypeSafe AI’s introduction to Jev.
  • Cattledog wraps any LLM with Lu’s honesty: it can say “I don’t know”, and it carries scars, which are memories of past mistakes. Cattledog will be released under Apache-2.0. More on Cattledog.
  • Lu is the persistent layer that watches all of this, learns from it, gets curious, and steers.

4. Related work

We looked for existing work on October 14, 2026. Each piece of this idea already exists somewhere. We did not find one system that combines a persistent, curious, self-improving overseer with Jev and an honesty-and-scars layer, steering agents mid-task without the user. That is only as far as our search went; we may have missed something.

  • Sophia (arXiv 2512.18202): an always-on Executive Monitor reads agents’ reasoning traces, has a curiosity drive, and sets its own goals. This is the closest match, but it has no Jev and no honesty or scars layer.
  • Foreman: an experimental Python supervisor that uses Jev to watch a Codex worker and steer, stop, retry or finish it. Supervision only; no persistent learning or curiosity.
  • Jev-Mem (arXiv 2609.23986): Jev controls an agent’s long-term memory.
  • Meta-Agent (canvas-org): learns from execution traces to improve the agent harness.
  • Shepherd (arXiv 2605.10913): a meta-agent that can watch, fork and rewind another agent’s run.
  • REFLEX (arXiv 2609.26532): uses Jev as an agent’s decision layer. Still to be read closely.

5. Open questions

  • Guardrails. What may Lu act on alone, and what needs the user’s approval? This has to be settled before Lu steers anything.
  • Cost. Jev is a paid service with no free credits, so a first proof of concept may need a local stand-in model for the decision layer.
  • Whether it helps. Nothing yet shows that this combination makes agents better. It would need to be built and measured against agents running without Lu.
  • Prior work. REFLEX and the other work above need a closer read to see how much of this they already cover.

6. Open source

Lu and Cattledog are open source now: Lu (github.com/dialectforge/lu, AGPL-3.0 plus a commercial license) and Cattledog (github.com/dialectforge/cattledog, Apache-2.0). This page is also available as Markdown.
