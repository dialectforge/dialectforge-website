Messenger In development

Two layers. DialectForge on the wire is designed to hide that it's a messenger at all. End-to-end encryption on the content means the server only ever handles sealed envelopes.

§ 1 Path
§ 2 Who sees what
PartyWhat they're designed to see
ISP / DPINoise

L1 dialect traffic with no messenger signature to block.

ServerSealed envelopes

End-to-end encrypted blobs it routes and doesn't store. It doesn't hold the keys.

RecipientYour message

The only party with the matching private key.

Under the hood: usernames come from identity public keys. The L2 seed is set up with an X3DH-style key agreement plus XOR consensus, with a post-quantum (Kyber) hybrid planned. It's a SwiftUI app for iOS and macOS.

Messages and keys aren't stored on the server. That's the design goal and the reason it's built this way; the open source release is how you'll be able to check it. Messenger has its own Terms and Privacy Policy.

The outside envelope hides that you're sending a letter at all. The inside envelope can only be opened by the person it's for. The post office isn't supposed to be able to open it either.

Start with an AI agent

Paste this into your AI coding agent. It points the agent at the repository's AGENTS.md (what's there, what works, which files to read first), the protocol notes and the license, then has it plan the integration with you.

I want to integrate the DialectForge protocol (Messenger) into my project. Before writing any code, read these in order:
1. AGENTS.md in https://github.com/dialectforge/dialectforge-messenger
2. https://dialectforge.com/protocol/
3. LICENSE, COMMERCIAL-LICENSE.md and CONTRIBUTING.md in that repository
Then ask me about my project (language, where data moves, what I want to protect) and propose a small integration plan for me to approve.
Treat every security property as a design goal: this code has not been independently audited. Tell me about the license obligations (AGPL-3.0, or a commercial license from DialectForge LLC) before copying any of its code into my project.

Repository: dialectforge/dialectforge-messenger. It is private while it is being cleaned up and will be public soon; the prompt works as-is once it is. All agent prompts.
