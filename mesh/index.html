Mesh / Tunnel

Server-to-server and database traffic, wrapped in DialectForge. The database connects to a local port and has no idea its traffic is crossing the internet in dialect.

§ 1 Before / after
§ 2 How

  1. Built into the server

    Mesh runs as a service on each machine. When servers come online their tunnel endpoints negotiate a dialect that only they share. There's no external auth service.

  2. Replication through the tunnel

    The primary runs a tunnel endpoint; each replica connects through it. The database software just talks to a local address.

  3. The mesh secret never crosses the wire

    All servers share a mesh secret, but it's never transmitted. Endpoints exchange nonces and derive a unique session seed for each connection, so the design intent is that capturing packets doesn't let you rebuild the secret.

  4. Session-mode dialects

    Replication is a continuous stream, and changing dialect mid-stream could corrupt data. So each tunnel connection holds its dialect for the life of the session, and new connections negotiate new ones.

I used this to link my own VPN servers while that service was running. Those servers are offline now. It hasn't been independently tested.

§ AI Agent

Start with an AI agent

Paste this into your AI coding agent. It points the agent at the repository's AGENTS.md (what's there, what works, which files to read first), the protocol notes and the license, then has it plan the integration with you.

I want to integrate the DialectForge protocol (Mesh / Tunnel) into my project. Before writing any code, read these in order:
1. AGENTS.md in https://github.com/dialectforge/dialectforge-mesh
2. https://dialectforge.com/protocol/
3. LICENSE, COMMERCIAL-LICENSE.md and CONTRIBUTING.md in that repository
Then ask me about my project (language, where data moves, what I want to protect) and propose a small integration plan for me to approve.
Treat every security property as a design goal: this code has not been independently audited. Tell me about the license obligations (AGPL-3.0, or a commercial license from DialectForge LLC) before copying any of its code into my project.

Repository: dialectforge/dialectforge-mesh. It is private while it is being cleaned up and will be public soon; the prompt works as-is once it is. All agent prompts.
